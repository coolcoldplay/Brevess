# Contributing

Thank you for helping improve Brevess for students and researchers.

- Open an issue before a large behavioral or architectural change.
- Do not commit API keys, authentication headers, browser profiles, user
  documents, or publisher diagnostic bundles containing page content.
- Add or update tests for behavioral changes and run `npm.cmd test`.
- Preserve upstream copyright and license notices for third-party code.
- Record copied or adapted external code in `THIRD_PARTY_NOTICES.md`.

By contributing, you certify that you have the right to submit the work and
agree that it is licensed under AGPL-3.0-or-later with the rest of the project.
