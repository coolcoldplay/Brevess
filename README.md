# SCI 论文逻辑关系高亮助手 2.4

这是一个 Chrome / Edge Manifest V3 扩展，用于在 HTML 论文页面中识别并高亮科学论述关系。2.3 使用原生浏览器侧栏，并同时提供离线正则模式和 BYOK（自备 API Key）LLM 全文模式。

完整的基础工作流、缓存策略和提示词字段见：[完整工作流与提示词参考](docs/SCI论文逻辑助手-完整工作流与提示词参考-v2.1.9.md)。2.2 的并发、Token 和 Figure 优化见：[性能与质量优化说明](docs/SCI论文逻辑助手-性能与质量优化-v2.2.0.md)。

## 核心能力

- 正则模式：完全离线，无需 API，保留原有规则编辑、导入和导出功能。
- LLM 模式：提取论文正文后进行语义识别，不先使用正则筛选候选句，避免漏掉不含固定关键词的表达。
- 正文过滤：排除参考文献、导航、页眉页脚、脚本、表单及其他非正文内容。
- 12 类内置关系：假设、目的、方法、结果、结论、对比、局限性、未来方向、因果、强调、证据和解释。
- 按需分析：只把当前勾选的类别写入提示词；新增类别时只分析尚未缓存的类别。
- 自定义 LLM 类别：支持定义、包含/排除条件、正反例、高亮范围和颜色；可长期保存或仅保留到本次浏览会话结束。
- 多 Provider：OpenAI、Anthropic Claude、Google Gemini、DeepSeek，以及 Kimi、智谱 GLM、豆包、通义千问、腾讯混元、百度千帆、MiniMax 等国内模型预设和自定义兼容接口。
- 本地反馈语料：点击 LLM 高亮可标记“准确”“不匹配”或改正类别。
- 语料导出与离线蒸馏：导出 JSONL/CSV；同一短语至少获得 3 篇不同文档的正向证据后，才会生成可导入的离线规则。
- 稳定性与速度：全文分块最多 3 路并发，支持断点续跑、局部失败保留、动态拆分和两级输出截断扩容；API 不可用时可回退到正则模式。
- 自适应阅读视图：内置“快速主线”“机制证据链”“批判性审读”“综述脉络”四套预设，并允许分别增删类别。
- 研究设计适配：用户从基础机制、临床前转化、观察性、临床试验、诊断/预后、组学、叙述性综述（机制/转化）、系统综述/Meta、方法/资源九类设计中单选一种，插件不替用户判断文献类型。
- 证据链与审计：同一关系可关联多段精确原文；缺失信息仅进入审计清单，不伪造页面高亮。
- 本地论文导航：无需 API，在正则和 LLM 模式都可从网页 HTML 立即生成完整分层标题树；全局 `+ / −` 可快速展开或收起层级，标题字号和字重随层级变化。
- 渐进式摘要与高亮分布：叶标题左侧 `+` 会展开与正文段落一一对应的摘要按钮；点击某一段只生成该段摘要。“章节 × 高亮类型”矩阵可跳回原文。
- Figure 解读与原图：加载时先从网页 DOM 和图注零 Token 建立 Figure / Panel 折叠目录；每个 Panel 可独立解读或提问，整图标准/深度审计仍按需触发。AI 解读只在右侧栏展示，全文高亮和 Figure 任务均可暂停、继续或取消。
- 文献全文问答：底部“问答”把当前网页正文作为会话上下文，每轮可切换任意已配置模型；回答以 Markdown 分点显示，可连续追问，并为每个引用段落提供独立的原文跳转点。
- 稳定正文计数：导航、全文问答和分析共用同一份去重后的正文段落快照；动态加载的新段落会刷新快照，重复的响应式 DOM 副本和父子容器不会重复计数。
- 按点击激活：普通网页不会自动扫描；点击扩展图标后才为当前论文注入提取模块并打开可拖动调宽的原生右侧栏。侧栏显示状态按标签页记忆：切到未开过插件的网页会自动收起；切回已经开过插件的文献页时 Chrome 会恢复显示，Edge 若触发其站点侧栏恢复限制，会出现轻量“恢复论文侧栏”入口，并在首次真实点击或按键时恢复。标签页导航到新网址后会重新等待手动激活。
- 单篇文献档案：高亮、备注、文献类型、正则/LLM 结果、证据台账、层级大纲、逐段摘要和 Figure 解读可保存为本地 JSON；重装后可导入并恢复到同一在线网页。
- 整机迁移：设置页可导出/导入完整配置、规则、提示词、Provider 配置、API Key、文献记录和反馈语料；导入后需重新选择本地目录。

## 安装

1. 打开 `edge://extensions/` 或 `chrome://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展程序”。
4. 选择包含 `manifest.json` 的本项目文件夹。
5. 修改源代码后，在扩展管理页点击“重新加载”。

浏览器商店的 ZIP 包不能直接在扩展管理页作为“解压缩扩展”加载，需要先解压。

## 使用方式

### 正则模式

在论文 HTML 页面点击扩展图标，右侧原生侧栏会打开并只在此时扫描当前页。选择“正则模式”，勾选类别后点击“应用高亮”。规则可编辑、导入和导出，所有处理都在本机完成。“整句”模式会跨上标、链接等内联节点识别完整句子，并避开 `Fig.`、`e.g.`、小数点等科学文本中的非句末句点。为降低误判，内置因果规则不再把单独的 `as` 或 `since` 当作充分证据。

### LLM 模式

1. 在右侧栏点击“API 设置”。
2. 若使用国内模型，选择“国内模型与兼容接口”，再选择 Kimi、智谱 GLM、豆包、通义千问、腾讯混元、百度千帆或 MiniMax 预设；插件会填入官方接口和默认模型。填写 API Key 后仍可按账户可用模型修改模型名称。
3. 勾选正文发送许可并保存。
4. 返回论文 HTML 页面，点击扩展图标，在右侧栏选择“LLM 精确模式”和阅读视图。
5. 在九种文献类型中单选一种。机制或临床前证据导向、没有系统检索与 Meta 流程的综述，选择“叙述性综述（机制/转化）”。首次 AI 分析前必须且只能选择一个研究类型。
6. 点击“分析全文”，生成自动高亮与证据台账。

LLM 模式不会先用正则表达式筛选候选句。插件会发送清理后的正文分块，但不会发送参考文献、网页地址、API Key 或本地反馈语料。

LLM 最低置信度默认是 80%。提高阈值会减少误判，降低阈值会增加召回。移动置信度拉杆只会使用页面中最近一次分析的原始标注重新高亮，不会再次调用 API；提示词或类别版本升级后，首次分析会重新生成缓存。

### 四种阅读视图

- 快速主线：聚焦已知背景、知识缺口、目标/假设、研究策略、关键结果、结论、创新意义和作者明确局限。
- 机制证据链：区分相关、干预因果、中介、必要性、充分性、补救、时序/剂量与跨系统验证，不把通路富集或共同变化自动升级为机制。
- 批判性审读：检查设计与对照、样本、测量效度、效应区间、统计稳健性、混杂/反向因果、外部验证、外推性和透明度。
- 综述脉络：聚焦综述范围与主旨、共识、矛盾证据、异质性来源、证据质量、整合框架和作者综合判断；共识与矛盾必须有两个不同的正文证据来源。

每个视图单独保存类别调整。快速主线默认保持精简；模型只接收当前视图和用户启用的类别。推断型批判警示采用不低于 90% 的硬阈值，并必须同时引用作者主张与判断依据。

### 当前视图、类别规则与手动标注

- 切换阅读视图后，侧栏优先显示当前视图的活动类别；“更多分类”用于按需加入其他类别，不会把全部类别堆在当前列表里。
- 每个类别都可点击“查看/编辑规则”，在设置页分别查看和编辑给 AI 的提示词与正则表达式，保存前还可安全试跑正则。
- 创建手动标注时，只选择同一段落内的文字，在浮动工具条选择类别颜色即可生成荧光笔高亮；再次点击高亮可更换类别并编辑备注。
- 自动识别（LLM 或正则）的文字使用彩色粗下划线，手动标注使用荧光笔背景，两者重叠时仍可区分。
- “清除自动高亮”只移除自动标记；“清除手动标注”需要确认，并只删除本文已保存的手动标注。两种清除互不影响。
- “待重新定位”表示页面结构变化后暂时找不到原锚点，不代表标注已被删除；可在原文中重新选择并绑定。

### 论文导航、逐段摘要与高亮分布

在任一识别模式点击“论文导航”，插件会直接读取当前 HTML 的正文根节点、官方目录锚点和 H1–H6/ARIA 标题，生成一棵完整分层标题树，不调用 API，也不要求先选择文献类型。顶部 `+ / −` 可展开或收起全部标题层级；不同层级使用不同字号和字重。点击标题文字可跳到原文章节。

导航面板打开期间会监听正文容器的增量加载，并在约 450 ms 防抖后合并新标题和段落；关闭面板立即断开监听器并释放临时树和高亮矩阵视图，不会把浏览过的所有页面 DOM 长期留在内存中。ScienceDirect 等带官方 Outline 的页面优先按锚点恢复章节，站点专用选择器失败时再回退到通用语义提取。

需要 AI 摘要时，在 LLM 模式单选文献类型后点击“生成逐段摘要”。最底层标题左侧的 `+` 会展开按原文顺序排列的单段摘要按钮；点击“第 N 段 · 点击生成摘要”只请求这一段，不会重做整篇。已有摘要可直接点击并返回对应原文。整篇任务仍支持分块进度、重试、自动拆分和断点续跑。

切换到“高亮分布”可查看“章节 × 高亮类型”矩阵。数字表示该章节中对应类别的高亮数量；点击章节名跳到章节，点击数字跳到该单元格中的第一处高亮。矩阵同时统计正则/LLM 自动粗下划线和用户荧光笔高亮，无法绑定章节的高亮会单独提示而不会被删除。

### 逐图解读

右侧“图解”页加载时会直接从网页 DOM、图注和可访问性标签识别全部 Figure 与 Panel，不调用 LLM。目录默认折叠；每个 Panel 都有“解读此 Panel”和“提问此 Panel”，只在点击后调用 Figure 路由。批量和单图入口仍可生成整图标准解读，需要对照、因果等级与替代解释审计时再点击深度解读。多 Panel Figure 会分批提取 Panel 证据，随后统一综合整图逻辑。点击“查看高清原图”会在当前网页左侧打开深色查看器，支持缩放、拖动、适配窗口、Esc 和关闭按钮。DeepSeek 官方 API 只使用图注和相关正文，插件会跳过图片下载、压缩与 Base64 编码；具备视觉能力的 Provider 才发送图片。

运行中可随时暂停、继续或取消。暂停会让当前在途请求自然完成，但不会继续发送下一批；取消会中止当前网络请求并保留已经完成的 Figure 或全文分块结果。批量运行不会强制展开所有 Figure，手动展开的 Figure、Panel、三个精读结论块和未提交追问会在进度轮询中保持。“多米诺论证链”“证据组织”“组间逻辑连接”默认分别折叠。图解页右缘悬停短横条时在左侧显示 Figure 名称；继续停留会再展开 Panel 列表，点击可平滑跳转并展开目标。

每个 Panel 保留“分组含义与设置、实验技术原理、横纵坐标含义与读图方法、实验所用样本信息”四个复选项，同时支持输入自定义问题。四个内置选项对应的模型指令可在“模型设置 → Panel 追问提示词”中全局编辑或恢复默认。

### 文献全文问答

底部“问答”以当前网页已提取的正文为上下文，支持连续对话，并允许每轮从所有已配置模型中自由切换。正文在上下文预算内时发送全文；超长文章会按问题相关性、关键章节和文章首尾选取内容，界面会显示发送段落数和是否截断。回答以 Markdown 显示，项目符号、编号、加粗和段落换行都会保留；聊天记录拥有独立滚动区，长回答不会被输入框遮挡。每个引用的正文段落会单独显示可点击的原文跳转点，回答边界可折叠。按 Enter 发送，Shift+Enter 换行；也可取消当前回答或清空本篇会话。

## 自定义识别类别

在“API 设置 → 自定义 LLM 识别类别”中填写：

- 类别名称和清晰的语义定义；
- 应当包含和应当排除的情况；
- 可选正例、反例；
- 短语、分句或整句高亮范围；
- 长期保存或仅本次浏览会话。

新类别默认被选中。只有侧栏中勾选的类别会发送给模型，因此只看某一类时不需要为其他类别消耗 Token。

## 反馈语料与离线规则

点击网页中的 LLM 高亮，可以确认、拒绝或改正类别。反馈只保存以下有限字段：文档内容哈希、段落 ID、章节标题、高亮文本、前后最多 240 个字符、类别、置信度和用户判断。

在“API 设置 → 本地反馈语料库”中可以：

- 导出 JSONL，用于后续训练或评估；
- 导出 CSV，便于人工检查；
- 生成与旧版规则导入格式兼容的 JSON 离线规则包。

蒸馏规则采取保守阈值：至少来自 3 篇不同文档的重复正向证据，且不能存在相同短语的拒绝证据。

## 本地数据目录、同步与内存

在“API 设置 → 本地数据与备份”中，按需使用“选择目录 → 重新授权 → 立即同步 → 从目录重建 → 导出 JSON 备份”。目录只保存可迁移的类别配置、文献标注和反馈副本；扩展自己的 IndexedDB 仍是日常工作的主数据源。

目录无权限或暂时不可写时，“待同步”只表示修改仍在持久化队列中，不代表数据已被删除。重新授权后可继续补写；“从目录重建”只导入目录索引声明且修订号更新的有效资产。

API Key、Provider 鉴权头、分析缓存、目录句柄和同步队列不会写入目录镜像或 JSON 备份。网页只显示所选目录名称，不显示操作系统完整路径。

每篇论文另有一个确定路径的文章档案。点击扩展图标后，插件只探测当前网址对应的这一个文件，不枚举整个目录；找到旧档案时会提示“加载上次结果”或“重新分析”。单篇档案不包含 API Key、鉴权头、完整网页 HTML 或图片数据。正文版本变化时只安全恢复备注、分析卡片等结果，不把旧文本范围强行套到新正文。

“整机迁移”与上述无凭据备份不同：它用于换电脑后完整恢复配置，因此导出的迁移文件会包含 API Key 和自定义鉴权头。文件导入前会二次确认；请像密码文件一样保管。浏览器不会迁移目录授权，导入后需重新选择本地保存目录。

浏览历史不会全部常驻内存：内存主要随当前页面及其当前文献标注数量变化；历史文献、类别和反馈保存在持久化存储中。论文导航只在面板打开时观察最多 6 个正文根节点，关闭即断开；增量刷新只保留标准化标题、段落锚点和计数，不保存出版社原始 DOM。待同步队列按资产路径合并连续修改，同一文献反复编辑只保留最新待写版本。

## 一键导出出版社适配诊断包

如果正文已经显示，但文献类型仍为灰色、标题树不完整或顶部提示提取失败，直接点击侧栏顶部固定的“导出适配诊断包”。这个按钮不依赖 `documentHash`，也不会为导出而重新运行正文提取器，所以即使提取器本身报错也能工作。

插件优先生成 `sci-adapter-diagnostic-<站点>-<时间>.json.gz`；旧浏览器不支持 gzip 时回退为 JSON。文件包含当前渲染后的网页 DOM、完整正文候选子树、出版社适配器与选择器命中情况、同源 iframe、开放 Shadow DOM、最近 40 次提取阶段及错误、最近一次成功的正文和结构快照。请把该文件、问题截图和“缺了哪些章节/哪里一直灰色”的简短说明一起交给开发者，即可针对页面实际 HTML 修复或新增适配器。

诊断包只在用户点击时临时生成，下载完成后释放内存，不会让所有浏览过的论文长期常驻。正文连接超过 15 秒会变为明确的“提取超时”状态，并显示“重新提取”；不会永久停留在“正在连接当前论文”。

## 隐私与安全

- API Key 使用浏览器扩展本地存储，不进入网页、日志、目录镜像、分析缓存或单篇文献档案；只有用户主动导出的“整机迁移”文件会包含凭据。
- 测试连接只发送插件内置的合成句，不发送当前论文。
- 自定义远程接口必须使用 HTTPS；仅 `localhost` 和 `127.0.0.1` 可使用 HTTP。
- LLM 结果必须引用正文中的精确原文；无法在本地重新定位的结果会被拒绝，不会高亮。
- OpenAI 请求关闭服务端存储选项（`store: false`）；其他服务商的数据处理仍以用户自己的服务协议为准。

## 已知限制

- 主要支持可访问 DOM 文本的 HTML 论文页面；Canvas、图片扫描件和多数内嵌 PDF 不在当前范围内。
- 主流出版社已使用站点适配器并保留通用语义回退；需要登录、正文尚未展开、反爬脚本、Shadow DOM、Canvas 或特殊阅读器仍可能限制提取。
- 真实 LLM 效果、价格、速率和数据政策取决于用户选择的模型服务商。
