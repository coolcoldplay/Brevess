# Brevess：性能与质量优化说明

## 1. 全文 LLM 高亮

正文仍按章节和段落边界切块，但最多同时处理 3 个独立块。每个成功块立即写入进度缓存，最终按 `chunkId` 稳定排序后合并，因此并发不会改变页面顺序。超时、输出截断或持续繁忙的多段块会动态二分；单块失败不会丢失其他已完成块。

全文高亮的自动输出预算为 `2400 + 320 × 段落数`，范围 4096—16384 Token。遇到明确的 Provider Token 上限拒绝时只向下调整一次；遇到完成原因为长度截断时最多上调两次，再由分块管线决定是否拆分。

## 2. Figure 解读

标准模式是默认入口，适合快速回答每个 Panel 做了什么、观察到什么以及整图结论。深度模式保留为按需操作，用于对照充分性、证据等级、替代解释、阴性结果和删去关键 Panel 后缺失环节的审计。

只有一批 Panel 时使用单请求快路径。需要多批时：

1. 每批只返回 Panel 局部证据，不重复整图字段；
2. 最多 3 批并行；
3. 每批完成即产生可恢复检查点；
4. 所有 Panel 到齐后，只调用一次整图综合。

Figure 自动输出预算范围为 6144—24576 Token；Figure 与跨图任务超时为 300 秒。结构校验失败时只允许一次严格 Schema 修复。

## 3. DeepSeek 路由

DeepSeek 官方 API 不具备本插件可验证的视觉输入能力，因此 Figure 请求仅包含图注和相关正文。2.2.0 会在内容脚本端提前读取有效 Figure 路由：若路由为文本模式，直接跳过图片下载、跨域回退、Canvas 缩放、JPEG 编码和 Base64 传输。

DeepSeek 请求使用非流式 JSON，减少 Service Worker/离屏网络层缓冲 SSE 的开销，并读取 `finish_reason` 和 `usage`。插件仍兼容少数无视 `stream: false`、继续返回 SSE 的兼容网关。

## 4. 建议配置

- 全文高亮：优先使用延迟较低的模型档位；保留自动 Token 模式。
- 批量 Figure：先跑标准模式，只有关键主图再做深度模式。
- 像素级读图：为 Figure 单独配置明确支持视觉的 Profile；不要期待 DeepSeek 文本路由识别颜色、曲线或显微结构。
- 遇到限流：降低同时进行的用户操作数量，并利用缓存续跑；不要反复强制刷新已成功 Figure。

## 5. 脱敏遥测

进度事件可包含 Provider、模型、耗时、完成原因及 Token 用量，用于判断瓶颈来自排队、输入过长还是输出过长。遥测不包含 API Key、Provider 原始错误正文或模型完整响应。
