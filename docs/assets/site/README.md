# Website demonstration media

## Real paper and AI recordings

Paper: Jumper, J., Evans, R., Pritzel, A. et al. **Highly accurate protein structure prediction with AlphaFold.** Nature 596, 583–589 (2021). [Original article](https://www.nature.com/articles/s41586-021-03819-2), DOI: 10.1038/s41586-021-03819-2. Reused under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The five reading-module demonstrations show the actual publisher page and BREVESS native Edge sidebar. They were captured separately and combined synchronously; static waiting was shortened. Full views add white padding below the shorter sidebar, and detail views crop the sidebar. AI annotations are separate from the published article and are not manually filled demonstration results.

The model was DeepSeek Flash. Navigation, highlights, Figure analysis and notes were generated in public r4. Q&A was generated in a separate development candidate with a bounded Harness stream compatibility fix; that fix is not included in the linked public r4 package. The notes retain an incomplete evidence-check warning. These recordings do not establish scientific validation of all generated output.

## Research workbench

The four workbench recordings use synthetic literature metadata and the built-in demonstration project. They show actual interface operations, without live PubMed search or AI calls. Metadata entries do not imply downloaded full texts.

The approved logo and support QR assets are unchanged. This folder contains only public website assets, with no server configuration, credentials or browser profiles.
