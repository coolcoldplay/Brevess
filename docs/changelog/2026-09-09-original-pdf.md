# 原页 PDF 阅读 — 本地 r9

本次把 PDF 原页接入 BREVESS 阅读工作区。显示层始终使用原 PDF 的页面、文字、图片和矢量内容；MinerU 只可补充索引，不会把阅读画面替换为解析后的重排正文。

## 已实现

- 从扩展按钮或设置页打开本地 PDF，也可输入 HTTP(S) PDF 地址。含文字层的 PDF 不需要 MinerU 即可建立本地索引。
- 翻页、页码跳转、搜索、缩放、适合宽度、页内链接和外部链接；按屏幕分辨率重绘，长文档限制同时挂载的页面数量，刷新后恢复阅读位置。
- 原页自动高亮、正则高亮、手动类别标注与备注。跨页划选保存为同组批注，缩放、页面卸载及重开后保留位置；可导出带标注的 PDF 副本。
- 划选问答、跨页选区与全文问答共享原文索引和可定位引用。保存的选区保留逐页原文绑定，重新生成前复核原 PDF、原句与段落指纹。
- Figure 目录与图注来自原 PDF。非视觉模型使用正文和图注；视觉模型可以接收原 PDF 页面图片。结果保留依据说明和缺失证据标记。
- 全部解图后可生成机制候选图和 Panel 证据表。待核验结果单独展示并保留，完成流程不再把正在查看结果的用户强制切回图解列表。

## 实际验证范围

测试使用隔离浏览器，没有修改用户的日常浏览器。真实 API 使用公开、23 页的 eLife 文献，实际发送新的 DeepSeek 请求，没有用预存回答替代模型响应。

- `deepseek-v4-flash`：原页自动识别与高亮、划选与全文问答、图注/正文解图、全部 4 张主图、机制候选与证据表及刷新恢复。
- `deepseek-v4-flash-vision-exp`：实际发送原 PDF 图片，单图解读与刷新恢复。
- 实际安装目录的机制验收生成 21 个候选节点、5 条有支持证据的候选关系；真实点击证据入口后可见 5 行、5 列证据表，刷新后内容指纹相同。该结果仍标为待核验，不代表所有科学推论已经人工确认。
- 实际安装目录跨页问答：鼠标划选跨越 2 页、3 个原文片段，首次生成与刷新后实际点击“重新生成”均完成，每个选中页都有经过精确原文定位校验的引用。两次均为新的 HTTP 200 请求；刷新保留选区与已有回答。
- 原页阅读、跨页手动标注、搜索、缩放、链接、导出和重开另有真实本地/远程 PDF 浏览器记录。
- 最终正常每文件隔离回归：3850/3850 通过，无失败、跳过或取消。安装目录入口验收 10/10 通过；Windows 伴随程序及内置 Java 健康检查通过，没有安装或注册操作，也没有产生模型请求。

## 边界

扫描件可按原页阅读。没有文字层时需要 OCR；真实 MinerU 扫描识别尚未完成端到端验收。透明 OCR 文字层的测试使用合成识别结果，只证明页面像素保持与坐标/缓存机制，不证明 OCR 准确率。

未宣称所有模型、所有 PDF 排版或加密文件均已通过。PDF 图解当前可使用整页原图作为证据，不保证每张图都有精确裁剪。模型可能给出不完整、待核验或缺乏证据的内容；产品保留对应状态，不补造引用。测试中也记录了格式不完整及提供方连接中断，修复和重试后的通过记录不会覆盖这些历史失败。

详细证据路径、状态与 SHA-256 见安装包 `PACKAGE_INFO.json`。API Key、浏览器配置、论文文件及模型原始响应不在安装包内。安装与升级方法见 `INSTALL.md`；升级现有开发版应保留同一扩展 ID 和加载目录，重新加载扩展并刷新文献页。
