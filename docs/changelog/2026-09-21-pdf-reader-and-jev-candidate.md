# 2026-09-21 本地验收候选版：PDF 阅读与 TypeSafe Jev

本构建是用于本地安装验收的候选版。具体构建名、文件哈希和本轮验收报告见包根目录的 `PACKAGE_INFO.json`；版本号仍为 1.0.1，以构建日期及 r13 区分旧 r12。

## 本次变化

- PDF 加载、识别、解图、保存和错误提示集中到右侧侧边栏的信息区，不再在 PDF 上方插入提示条挤占阅读空间。恢复操作也可从侧栏或阅读器“更多”菜单触发。
- PDF 保持原页显示，增加本地文字、句子、标题及原文坐标索引。原文引用、划选问答和笔记可返回对应原页。
- 跨页 Figure 将图像所在页与图注所在页分开处理。在 Figure 卡片中核对图像页后，按所选顺序提交最多四页图像；识别出的 Panel 保留实际页码归属。
- 解图保存与刷新恢复保留结果及来源。证据不足而无法辨认的 Panel 明确保留该状态，不以补猜结果换取任务完成。
- 新增 TypeSafe Jev 文本高亮连接。它只用于文本类别识别，不用于生成问答、笔记或解图。设置方法见 [TypeSafe Jev 说明](2026-09-21-typesafe-jev.md)。
- 保留此前的网页论文阅读功能与新版图标。

## 验收边界

功能链路通过不等于科学解释全部正确。模型的显著性比较、因果关系、图形读取和引文支持仍需结合原文核对。整图分组和机制网络尤其不能替代人工科学判断。

本次跨页开发实测使用两页图像、14 个 Panel 的公开论文，真实模型为 `deepseek-v4-flash-vision-exp`，保存前后结果哈希一致。该结果只覆盖固定样本；不代表任意 PDF 或任意模型的准确率。完整测试来源和最终构建对应关系以验收清单为准。

以下质量验证尚未完成，不作为本包的已验证能力：

- 8 篇 PDF、120 个句子、80 个标题及 30 个章节范围的正式人工语料门槛；已有小样本开发测试不能替代该门槛。
- 真实扫描 PDF 经 MinerU 的识别准确率和坐标准确率，以及真实文字/扫描混合 PDF 的完整流程。扫描件原页可读不等于文字识别成功。
- Jev 多论文泛化准确率。现有冻结真实论文样本为一篇、8 例，结果 7/8，其中研究目标句有一次漏报；没有为此降低阈值。
- PDF 首次远页引用的稳定低延迟。部分运行存在数秒绘制等待，后续热缓存运行较快；长尾原因尚未完全定位。

## 安装

请按包根目录 `INSTALL.md` 升级，先备份重要档案。不要先卸载现有扩展，以免丢失其浏览器存储。生成本包不会自动替换日常扩展、注册本机伴随程序或修改 Zotero 原文件。

包内不包含 API Key、浏览器配置、私人论文及验收时的模型原始响应。
