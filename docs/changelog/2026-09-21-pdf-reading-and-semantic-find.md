# PDF 阅读体验与 J 语义查找

本次针对真实 40 页双栏论文的划选、滚动和显示问题修复，同时加入 J 语义查找。r13 保留原样；以下改动进入新的候选包，最终验收范围以该包构建说明为准。

## PDF 显示与划选

- 按实际文字几何识别窄栏间距，保留词间空格、行末和上标引用的位置，避免在左栏拖选时带入右栏或页脚。
- 补齐独立阅读器所需的 PDF.js 缩放变量，使透明文字层与原 PDF 字形对齐。
- 在不改变原文、原生选区或正式标注的前提下，将同一 PDF 行内的临时选区连起来。取消选择后移除临时外观。
- 文字层先在脱离页面的容器内生成，再验证当前文档和渲染任务后一次提交，避免逐个文字节点写入页面造成持续布局。
- 优先渲染实际可见页；高分屏可见页按设备像素比生成位图。升级清晰度时保留旧位图，成功后再替换。
- 阅读进度、错误和保存等信息继续显示在右侧侧栏的信息区，不增加 PDF 正文上方的信息栏。

在用户提供的论文、197% 缩放下，同一组向下滚轮操作从 36.616 秒缩短至 4.077 秒，最长主线程任务从 21.663 秒降至 231 毫秒。原先耗时 21.503 秒的第 6 页文字层在后测中约需 20 毫秒。该数字来自固定本机与指定操作，不代表所有 PDF 或设备的速度；复杂页首次位图仍可能需要数秒。

## 图解与证据块

- PDF 模式点击“原图”直接定位原 PDF 对应页。已选 Panel 有经过校验的页码时使用该页，否则定位该 Figure 的首个图像页。解析文本视图下会先切回原页。
- 展开一个证据块后直接显示其 Panel 卡片，移除中间的“Panels · N”折叠；每个 Panel 的详细解读仍可单独展开。
- 网页重载时，后台和侧栏共用同一文档的脚本注入锁，避免同时初始化造成重复声明；当前文档的接收器和浏览器文档 ID 都经过核对。

## J 语义查找

按 J 输入要查找的含义，以 TypeSafe Jev 返回的匹配分值深浅临时高亮原句。Enter / Shift+Enter 切换，Esc 退出；手动确认类别的高亮保留。网页和 PDF 共用独立的模型设置入口。具体覆盖限制、快捷键设置和分值说明见 [J 语义查找](2026-09-21-semantic-find.md)。

模型匹配分值不是经过准确率校准的正确概率。当前工作验证交互与原文定位，不替代多论文科学质量评测；扫描 OCR 和 Figure 解读的既有科学限制继续保留。
