# J 语义查找

在已启用 Brevess 的论文网页或内置 PDF 阅读器中按 **J** 打开语义查找。输入要找的含义，例如“为了验证某个假说而设计的实验”，按 Enter 开始。查询可用中文，匹配原文可以是英文。

- 命中的原句以琥珀色临时标出；模型匹配分值越高，颜色越深。分值直接来自 TypeSafe Jev 的 noul 返回值，不是经过准确率校准的正确概率。
- 默认显示分值不低于 0.70 的句子，可在搜索框中调整最低分值。检索检查可提取正文中的全部句子，低于显示阈值的句子仍计入处理进度。
- 相同查询再次按 Enter 查看下一条，Shift+Enter 查看上一条，按文档顺序循环。输入改变后，Enter 开始新的查询。
- Esc 退出并移除临时结果。点击命中句子可使用现有手动高亮工具栏选择内置或自定义类别；已经确认保存的正式标注会保留，支持原有编辑与重开恢复。
- 搜索框中的“模型设置”直接定位设置页的“语义查找”任务。它使用独立任务配置，默认选择可用的 TypeSafe Jev Profile；无可用配置时提示配置，不会自动切换到不能返回原生概率的生成模型。支持填写 TypeSafe 模型版本。快捷键可在原有快捷键设置中调整或禁用。
- 输入框、可编辑区域、中文输入法组合输入，以及 Ctrl/Alt/Meta 组合键不会触发 J 搜索。浏览器原有 Ctrl+F 保持可用。

PDF 搜索基于全文语义索引，覆盖尚未挂载到屏幕的页面。缩放和页面重新挂载后重新定位原句；更换文档使旧结果失效。未识别的扫描页、索引未完成或超长句子会明确显示部分覆盖。搜索不会自动启动 OCR。

搜索数据仅保存在当前会话内；确认归类才进入现有标注存储。每次查询最多 10,000 句、5,000 段和 4 Mi 字符；超出会明确提示。模型请求按最多 64 句及 TypeSafe 输入字节限制分批，按批次显示结果。实际等待时间取决于正文长度和模型服务延迟。

本功能从 r14 本地候选包起提供；具体验收范围见 [r14 验收说明](../releases/2026-09-21-r14-acceptance.md)。
