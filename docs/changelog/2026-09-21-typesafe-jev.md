# TypeSafe Jev 文献高亮接入

状态：已接入开发版，真实 API 与浏览器功能验收通过；尚未更新安装包。此次插入功能不代表 PDF 全功能验收完成。

## 使用方式

1. 设置中心 → 模型与连接 → 新增配置，Provider 选择 `TypeSafe Jev（文本高亮）`。
2. 输入 API Key。模型默认 `jev-latest`，也可以手填型号，例如 `jev-1.13.0`。联网获取列表只是建议，不限制手填型号。
3. 在“按功能指定模型 → 高级任务设置 → 文献高亮”选择该配置，保存连接并测试。
4. 亮文中选择 LLM 模式，使用内置或自定义阅读情境和类别，再应用高亮。

Jev 使用 TypeSafe 的原生 typed-decision 接口，仅承担句子分类与证据定位。问答、笔记、解图仍选择生成模型；Jev 不会出现在这些任务的可用模型列表中。没有生成模型时，附加证据审阅不可用，但已验证的高亮仍保留。

## 实现边界

- 分类可多选，使用用户保存的类别定义、包含/排除条件与示例；阴性结果仍可属于“实验结果”。
- 高亮和必需信息槽位绑定原文位置，保留科学符号、否定与数字；不由 Jev 编写改述文本。
- 请求按容量分批。缺失/畸形响应、取消和超限返回明确失败，不把服务错误伪装成“没有需要高亮的句子”。
- 密钥只进入本机配置或验收代理内存；本次报告仅含合成文本、已授权的公开论文原句及脱敏请求记录。
