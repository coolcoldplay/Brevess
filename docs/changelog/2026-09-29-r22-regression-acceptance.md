# R22 验收说明

本页随浏览器包提供。最终构建号、ZIP 校验值和包内检查结果见交付目录的 ACCEPTANCE.md。R22 用于验收本轮程序修复；科学解读仍需逐图核对。

## 如何更新

已有 R21.2 用户使用 browser.zip 即可；本地伴侣程序沿用与 R21.2 相同的已验组件。

1. 等当前分析任务结束，从旧扩展导出重要档案和迁移备份。
2. 将浏览器 ZIP 解压，把完整浏览器文件更新到原扩展加载目录。
3. 在浏览器扩展管理页点击重新加载，再刷新论文页。不要卸载旧扩展。
4. 保留 R21.2 包用于回退。程序文件回退不会自动回退你的资料。

扩展 manifest 版本仍为 1.0.1，用 PACKAGE_INFO.json 中的 R22 构建号区别本候选。工具没有替你安装或修改原加载目录。

## 科学内容如何继续验收

结构完整、标题变短，只证明对应程序检查通过。已记录的组别、染色通道、单位、统计值和图注冲突问题继续作为固定反例。

重点复核 Figure 3：B 为 3KL；A/B/F 的通道标签包含 βIII-tubulin/CD3；J 的 CD4 与 CD8 象限和数值必须对应；L 的分母为神经节；M 为 P=0.0005，N 为 P<0.0001，T 为 P=0.592/0.423。不能把其他 Panel 的数字移入当前 Panel，读不清的均值不应编造。

Figure 1 的 N/O 图像标签与原文图注存在冲突；Figure 3 的 H/I 组别和 O–Q 时间起点也有来源差异。解读应明确指出冲突、保留各来源，不静默认定一边正确。

后续修复按三个步骤验收：先证明输入图注忠实于原文；再用相同图片和固定 Panel 反例核对新输出；最后再检查整图归纳有没有加入无依据的因果或统计结论。不会以反复调用后挑一个好答案作为通过依据。
