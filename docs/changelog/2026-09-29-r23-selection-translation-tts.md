# R23 验收说明：划句、引文与朗读

本候选延续 R22，包含 HTML/PDF 划句响应、自动翻译、Alt 等待提示、翻译正文提取和选区朗读。最终包检查结果见发行目录的 ACCEPTANCE.md。

## 更新与打开

保存现用版本和重要论文档案。把浏览器 ZIP 完整解压到原扩展加载目录并在扩展管理页重新加载，然后刷新已打开的论文页。保持原扩展 ID，无需卸载。已有本地伴侣沿用，无需为朗读重新安装伴侣。工具没有替你安装或改写用户数据。

Kokoro 使用你现有的 D:\AI\Kokoro-TTS 安装。先按原方式启动服务；默认接口为 http://127.0.0.1:8880/v1/audio/speech，模型 kokoro，英文 af_heart，中文 zf_xiaoxiao，无需 API key。

## 建议逐项测试

1. **划句弹窗**：在 HTML 正文短拖选、长拖选，松开后弹窗应保留并开始翻译。点击别处或关闭按钮仍应关闭；换选区后旧译文不能覆盖新选区。
2. **PDF 首屏**：打开有可选文字的 PDF，首屏出现后即可划句翻译或朗读。标注索引未完成时备注、AI 和规则操作暂不可用；就绪后重新划句即可使用。测试同页及跨页，确认没有额外页眉页脚。
3. **Alt 段落**：按既有 Alt 操作触发翻译，等待时段末应有转圈；成功、失败或取消后消失。连续换段落时不能在旧段落留下转圈。
4. **引文清理**：在含数字上标和参考文献预览的论文上分别测试全文、Alt 段落及划句。译文不应夹带隐藏的作者、期刊、Crossref/Scopus/PubMed 检索链接等内容；原文、高亮位置、公式与正常脚注不应被删除。
5. **朗读按钮**：选中文字，点击情境下拉箭头右侧的扬声器；再次点击停止。合成时有等待状态；切换选区或关闭弹窗停止旧播放。若浏览器提示需要点击播放，点击一次播放按钮即可继续。
6. **朗读设置**：打开“设置 → PDF 与阅读工具 → 选区朗读”。修改语速、英文/中文音色并保存，刷新音色、试听，再重开设置检查保留。自动朗读默认关闭，开启并保存后新选区自动朗读。含中文的选区使用中文音色。

在线模式支持兼容 OpenAI 语音接口的 HTTPS 服务。填完整 `/audio/speech` 地址、模型、音色及服务要求的 key，保存后生效。仅向当前选中的配置发送所选文字；连接失败不会自动切到其他服务。key 保存后不回显，留空保留，勾选清除才删除。

## 仍需区分的情况

- 浏览器首次使用本地翻译、需要下载资源或不支持该语言时，可能仍需要点击“开启本地翻译”。本机资源可用时，在真实正文按下鼠标的手势中准备模型，避免长拖选丢失首次激活；这不绕过浏览器要求。
- 本轮本地 Kokoro 已进行真实中英文短句合成。在线服务的具体账号、费用和音色没有替你调用测试。
- 图解的科学准确性仍未通过。R22 已记录的组别、通道、单位、数值等错误继续保留，不能把本包交互通过视为科学内容通过。
