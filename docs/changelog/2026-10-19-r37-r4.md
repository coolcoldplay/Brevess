# Brevess 1.0.1 · R37 r4

This revision adds shared highlights and Figure/Panel discussions, integrated
account management, model settings improvements, and complete English UI work.

- Settings → Account management contains registration, email verification,
  login, password management, groups and invitations. The toolbar popup shows
  account status and opens the same settings page.
- Shared highlights are opt-in. Sentences with shared notes receive an
  underline; readers can open discussions and filter by research group.
- Figure/Panel discussions support replies, likes, and sorting by time or likes.
  Shared content requires a signed-in BREVESS account and the appropriate group
  membership. Private notes remain local unless explicitly shared.
- Add a model connection by choosing a provider and entering an API key.
  Models initialize automatically. The feature table configures each task's
  model, thinking, reasoning effort, supported web search and token rules.
- Choose a local save folder once; ordinary document saves no longer require
  the optional model-configuration backup password. Revoked browser directory
  permissions still require recovery.
- Existing saved preferences and model routes remain compatible. English UI,
  prompts, dynamic messages and exports have updated translations.

This repository contains the browser extension and its local companion source.
Shared-account features require a separately configured service. Hosting code,
deployment files, live service settings, accounts, databases and credentials are
excluded from this publication.

## Verification

The extension candidate passed controlled provider payload tests, configuration
round trips, isolated Edge model/settings tests, local save/restart tests,
account/group tests and HTTPS integration. These checks do not establish the
availability or answer quality of a real paid model service. Native Windows
directory-picker permissions still need manual confirmation on each machine.

For this publication, the extension dependency lockfile and relevant unit tests
are retained. No API keys or local user files are required to run unit tests.

## Public test package

Download the browser-only ZIP from the [R37 r4 test release](https://github.com/coolcoldplay/Brevess/releases/tag/v1.0.1-r37-r4-public).
Extract it and load the `browser-extension` folder in Edge/Chrome Developer mode.
`START-HERE.md` provides Chinese/English instructions. No operational sharing URL,
native companion binaries or server deployment files are included. Ask your group
owner privately for the sharing service URL and enter it in Settings → Account
management → Advanced · Service connection before registering or signing in.

To reproduce the package from a clean checkout of this release's source commit:

```powershell
$releaseCommit = git rev-parse HEAD
node scripts/build-public-test-release.mjs dist/Brevess-v1.0.1-R37-r4-public-test $releaseCommit
Add-Type -AssemblyName System.IO.Compression.FileSystem
[IO.Compression.ZipFile]::CreateFromDirectory((Join-Path $PWD 'dist/Brevess-v1.0.1-R37-r4-public-test'), (Join-Path $PWD 'dist/Brevess-v1.0.1-R37-r4-public-test.zip'))
```

Use a fresh destination. `PACKAGE_INFO.json` records the source commit and file
hashes; ZIP timestamps may differ between builds. No dependency installation is
needed to package the existing browser runtime.
