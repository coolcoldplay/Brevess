# Brevess v1.1 - 新功能说明

本次更新（v1.1.0）带来了众多强大的新功能，让插件更加灵活和易用！

## 📊 新功能详解

### 1. 实时匹配计数 ⭐⭐⭐⭐⭐

**功能说明**：
插件会自动扫描当前页面，统计每个逻辑关系类别的匹配数量。

**使用方法**：
1. 点击插件图标打开面板
2. 自动显示：
   - 标题旁显示"共 X 处匹配"（总数）
   - 每个类别右侧显示该类别的匹配数
3. 应用高亮后，匹配数会实时更新

**使用场景**：
- 📖 快速了解论文的逻辑结构密度
- 🎯 找到某类表达最多的部分
- 📈 分析不同论文的写作风格差异

**示例**：
```
逻辑关系类别 [共 156 处匹配]

☑️ 提出假设 [8] - 8个匹配
☑️ 研究目的 [15] - 15个匹配  
☑️ 结果陈述 [42] - 42个匹配
☑️ 结论总结 [12] - 12个匹配
```

---

### 2. 完全可编辑的规则系统 ⭐⭐⭐⭐⭐

**功能说明**：
现在可以编辑所有规则，包括12个内置默认规则！

**可编辑内容**：
- ✏️ 类别名称
- 🎨 高亮颜色
- 📝 匹配模式（简单列表或正则表达式）
- 🗑️ 删除规则（包括默认规则）

**使用方法**：

#### 编辑规则
1. 点击任意类别右侧的 ✏️ 按钮
2. 在弹出的对话框中修改：
   - 类别名称
   - 高亮颜色（色板或输入#RGB值）
   - 规则类型（简单列表/正则表达式）
   - 匹配模式
3. 点击"保存"

#### 新增规则
1. 点击"➕ 新增规则"按钮
2. 填写所有信息
3. 保存后自动选中并生效

#### 删除规则
1. 点击类别右侧的 🗑️ 按钮
2. 确认删除
3. 注意：删除的内置规则可通过导入默认配置恢复

**使用场景**：
- 🎨 调整颜色到你喜欢的配色方案
- 📝 补充遗漏的常用表达
- 🗑️ 删除不需要的类别
- ✏️ 根据学科特点定制规则

**示例**：

修改"提出假设"类别：
```
原名称：提出假设
新名称：研究假设 ✓

原颜色：#FF6B6B (红色)
新颜色：#9B59B6 (紫色) ✓

原模式（部分）：
we hypothesize, we propose, we postulate

新增模式：
+ we speculate that
+ it is speculated
+ our speculation
```

### 3. 规则导出/导入 ⭐⭐⭐⭐⭐

**功能说明**：
将所有规则配置导出为JSON文件，可用于备份、分享或在不同设备间同步。

#### 📤 导出规则

**使用方法**：
1. 点击"📤 导出规则"按钮
2. 自动下载JSON文件
3. 文件名格式：`sci-highlighter-rules-1732512345678.json`

**导出内容**：
- 所有规则（默认+自定义）
- 规则的所有属性（名称、颜色、模式、类型）
- 不包括：选中状态、高亮模式

**使用场景**：
- 💾 定期备份你的配置
- 👥 分享给同事或同学
- 🔄 在不同电脑/浏览器间同步
- 📚 为不同学科创建不同配置集

#### 📥 导入规则

**使用方法**：
1. 点击"📥 导入规则"按钮
2. 选择JSON文件
3. 选择导入方式：
   - **合并**：保留现有规则 + 添加新规则
     - 如果规则ID相同，新规则会覆盖旧规则
   - **替换**：删除所有现有规则，使用导入的规则
4. 导入完成，立即生效

**使用场景**：
- 🆕 在新设备上快速配置
- 👥 使用他人分享的规则
- 🔄 恢复之前的备份
- 📚 切换不同的规则集

**分享规则示例**：

团队场景：
```
研究组长：导出团队统一的规则配置
↓
发送JSON文件给组员
↓
组员：导入规则（选择"替换"）
↓
全组使用统一标准
```

### 4. 正则表达式支持 ⭐⭐⭐⭐

**功能说明**：
高级用户可以使用正则表达式创建复杂的匹配规则。

**两种规则类型对比**：

| 特性 | 简单列表 | 正则表达式 |
|------|---------|-----------|
| 难度 | 简单 | 需要学习 |
| 功能 | 基础 | 强大 |
| 适合 | 大多数用户 | 高级用户 |
| 示例 | `we found, we observed` | `we (found\|observed\|discovered)` |

**使用方法**：

1. 新增或编辑规则时
2. 选择"正则表达式"类型
3. 输入正则表达式
4. 系统会验证格式
5. 保存

**正则表达式示例**：

基础示例：
```javascript
// 匹配 "figure" 后跟数字再跟 "shows"
figure\s*\d+\s*shows

// 匹配结果：
✓ figure 1 shows
✓ figure 10 shows  
✓ figure  3  shows
```

进阶示例：
```javascript
// 匹配多种图表引用
(figure|table|fig\.?|tab\.?)\s*\d+\s*(shows?|demonstrates?|illustrates?)

// 匹配结果：
✓ Figure 1 shows
✓ Table 2 demonstrates
✓ Fig. 3 illustrates
✓ figure 5 show
```

高级示例：
```javascript
// 匹配百分比增长/下降
(increase|decrease|rise|fall)[sd]?\s+by\s+\d+\.?\d*\s*%

// 匹配结果：
✓ increased by 25%
✓ decreases by 12.5%
✓ rose by 50%
```

**注意事项**：
- ⚠️ 系统会自动添加不区分大小写标志（`i`）
- ⚠️ 不需要添加单词边界（`\b`）
- ⚠️ 确保正则表达式格式正确，否则无法保存

### 5. 智能Tooltip提示 ⭐⭐⭐⭐

**功能说明**：
鼠标悬停在高亮文本上时，显示详细信息。

**显示内容**：
- 📋 逻辑关系类别名称
- 🔍 实际匹配到的关键词（整句模式特别有用）

**使用方法**：
1. 应用高亮后
2. 将鼠标移到任意高亮文本上
3. 自动显示tooltip
4. 移开鼠标，tooltip消失

**两种模式的tooltip差异**：

**单词/短语模式**：
```
悬停在 "we hypothesize" 上：
┌─────────────────────┐
│ 📋 提出假设           │
│ 匹配词：we hypothesize │
└─────────────────────┘
```

**整句模式**：
```
悬停在高亮的整句上：
┌────────────────────────────────┐
│ 📋 提出假设                      │
│ 匹配词：we hypothesize          │
│                                │
│ （整句被高亮，但清楚显示是       │
│  哪个关键词触发了匹配）          │
└────────────────────────────────┘
```

**视觉效果**：
- 🎨 深色半透明背景
- 💡 类别名称使用高亮颜色
- ✨ 平滑淡入淡出动画
- 📍 智能定位（不超出视口）

### 6. 颜色记忆功能 ⭐⭐⭐⭐

**功能说明**：
修改任何规则的颜色后，会永久保存，直到你再次修改。

**工作原理**：
1. 修改颜色
2. 保存规则
3. 颜色信息存储在浏览器本地
4. 重启浏览器后依然保持
5. 导出规则时包含颜色
6. 导入规则时应用颜色

**使用场景**：
- 🎨 创建个人配色方案
- 👥 团队统一配色标准
- 🔄 在不同设备保持一致

## 💡 实用技巧

### 技巧1：为不同学科创建专属规则集

**场景**：生物学论文和计算机论文的常用表达不同

**方法**：
1. 创建"生物学"规则集：
   - 添加领域特定表达
   - 调整颜色为冷色调
   - 导出为 `bio-rules.json`

2. 创建"计算机"规则集：
   - 添加技术术语
   - 调整颜色为暖色调
   - 导出为 `cs-rules.json`

3. 使用时：
   - 读生物论文：导入 `bio-rules.json`
   - 读计算机论文：导入 `cs-rules.json`

### 技巧2：团队协作规则管理

**场景**：研究团队需要统一标准

**方法**：
1. 负责人定制规则：
   - 根据团队需求调整
   - 添加常用表达
   - 统一颜色方案

2. 导出并分享：
   - 导出规则文件
   - 通过邮件/网盘分享给成员

3. 成员导入：
   - 选择"替换"模式导入
   - 确保使用相同配置

### 技巧3：渐进式学习正则表达式

**场景**：想用正则但不熟悉语法

**方法**：

第1阶段 - 从简单开始：
```
// 固定词组
we found
```

第2阶段 - 使用或运算：
```
// 多个选项
we (found|observed|discovered)
```

第3阶段 - 添加量词：
```
// 可选空格
we\s+(found|observed)
```

第4阶段 - 使用通配：
```
// 数字匹配
figure\s*\d+\s*shows
```

第5阶段 - 组合复杂模式：
```
// 完整模式
(figure|table)\s*\d+\s*(shows?|demonstrates?)
```

### 技巧4：利用匹配计数优化规则

**场景**：不确定某个规则是否有用

**方法**：
1. 添加新规则
2. 打开插件查看匹配数
3. 如果匹配数为0：
   - 检查表达是否正确
   - 或删除该规则
4. 如果匹配数很多：
   - 确认是否误匹配
   - 调整规则精确度

### 技巧5：创建个人高亮词库

**场景**：积累常用的学术表达

**方法**：
1. 阅读优秀论文时
2. 发现好的表达
3. 立即编辑相应规则添加
4. 定期导出备份
5. 逐步建立个人词库

## ❓ 常见问题

### Q1: 修改颜色后，重启浏览器颜色还在吗？
**A**: 是的！所有修改都会永久保存，直到你再次修改或删除插件。

### Q2: 可以恢复默认规则吗？
**A**: 可以！插件包中有默认规则配置文件，导入即可恢复。

### Q3: 导入规则时选"合并"还是"替换"？
**A**: 
- **合并**：保留你的自定义规则，添加新规则
- **替换**：完全使用新的规则集（慎用）

### Q4: 正则表达式写错了怎么办？
**A**: 系统会验证格式，如果错误会提示"格式错误"，无法保存。

### Q5: 删除内置规则后能恢复吗？
**A**: 可以！通过导入默认规则文件恢复。建议删除前先导出备份。

### Q6: 匹配计数不准确怎么办？
**A**: 
1. 刷新页面
2. 重新打开插件
3. 如果问题持续，检查规则是否正确

### Q7: 如何查看规则文件的内容？
**A**: 用文本编辑器（如记事本、VSCode）打开JSON文件即可查看。
