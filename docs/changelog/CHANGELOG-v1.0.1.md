# Brevess 1.0.1

`1.0.1` 是基于首个公开版本的功能与隐私安全更新。

## 新增功能

- 新增 PDF 研究工作区，支持本地 PDF、网页 PDF、MinerU 结构化解析和补充材料绑定。
- 新增本机 PDF Figure 提取与 Java 回退引擎，发布包附带所需许可证和通知。
- 新增统一研究逻辑图，集中组织逐图问题、结论、证据组、跨图机制链和补充证据。
- 新增密码保护的便携配置备份与恢复，明文 API Key 不写入授权文件夹。

## 改进

- 改进 Figure/Panel 提取、PDF 标题层级、图片缓存和工作区恢复。
- 改进内容脚本热刷新、跨标签页激活、Native Messaging 和本机 Codex 状态恢复。
- 将历史 changelog 与早期版本说明移至 `docs/changelog/`，缩短仓库主页。
- 更新安装、隐私、开放源码、商店发布和第三方依赖文档。

## 隐私与发布卫生

- 工作区、诊断、导出和便携配置统一过滤凭据、认证头及敏感嵌套字段。
- 公开仓库和发布包不包含个人 API Key、浏览器资料、本地论文、Zotero 语料或 QA 截图。
- Edge 扩展 ZIP 与可选 Codex Bridge 分开发布；扩展包不包含本地可执行文件。

## 验证

- 1418 项自动化与契约测试通过。
- PDF 本机宿主测试通过。
- 发布 ZIP 的结构、版本、依赖声明、SHA-256 和敏感信息扫描通过。

## 版本

- 扩展版本：`1.0.1`
- 运行修订：`1.0.1-build1-store-release`
