# 2.0.1 变更记录

## Elsevier/Cell 完整正文修订 r5（2026-07-17）

- 修复 ScienceDirect/Cell 页面把重复 `.Body` 叶节点误当成整篇正文根的问题；当多个片段属于同一上层正文容器时，改为选择覆盖全部片段且得分更高的完整根节点。
- 正文识别不再只依赖 `<p>` 或无 class 的 `DIV`；带 class 的叶级 `DIV/SECTION/BLOCKQUOTE/DD` 在满足正文长度与句子特征时也会进入段落树，解决 Cell 综述“标题很多、正文段落大量为 0”的问题。
- 新增“导出页面诊断”按钮和独立诊断脚本，导出候选根、选择器命中数、标题样本、未识别文本块统计与最终提取结果；报告不包含完整正文段落。
- Playwright 浏览器回归已验证 ScienceDirect 分片结构为 6 标题/6 段、Cell classed-DIV 结构为 11 标题/11 段，并实际下载诊断 JSON。

## 旧标签页动态注入修订 r4（2026-07-17）

- 修复扩展加载后直接在既有论文标签页打开导航时，动态注入清单遗漏文章结构模块而报 `Article structure module must be loaded before extraction` 的问题。
- 动态注入现与 `manifest.json` 的内容脚本顺序完全一致，依次加载出版社适配、文章结构、正文提取、高亮分布、图文分析和手动标注依赖。
- 回归测试直接比较动态注入清单与 manifest，防止以后新增内容模块时再次漏同步。

## ScienceDirect 整篇正文根修订 r3（2026-07-17）

- 修复 ScienceDirect 页面同时存在整篇 `#body/.Body` 与单章节 `.article-body` 时，r2 会错误选择单章节、最终只显示 1 个标题和 1 段正文的问题。
- ScienceDirect 只把 `#body`、`.Body`、`[data-aa-name="article-body"]` 和 `.article__sections` 视为可信整篇根，不再把叶级 `.article-body` 当作整篇根。
- 出版社明确声明的可信正文根不再因为页面附带目录、指标等功能标题而输给更小的子容器。
- 新增与用户截图一致的多章节正文根回归测试，并保留 PLOS 等出版社优先使用专属正文根的既有行为。

## OA 出版社适配修订 r2（2026-07-17）

- 使用真实 Edge 扩展环境验证 Springer Nature、Taylor & Francis、PLOS、Frontiers、MDPI、ACS、AAAS/SPJ 和 bioRxiv OA 全文。
- 修复 PLOS 伪 `Article` 节点、ACS 标题栏污染、AAAS 作者信息混入、bioRxiv 目录漏标题及超大容器跳转不准确。
- 出版社安全验证页现在返回 `NON_ARTICLE_CHALLENGE`，不会被当作论文正文，并在导航面板显示明确提示。
- 高亮分布矩阵已在真实 PLOS 页面验证章节归类、分类计数和点击回跳。
- 连续打开/关闭导航 40 次后无残留面板节点或重复段落标记；完整回归测试 502 项全部通过。

发布日期：2026-07-16

## 本地论文导航与出版社适配

- 新增无需 API 的“论文导航”，在正则和 LLM 模式均可从当前 HTML 立即生成可折叠标题树，并点击跳转到原文章节。
- 新增 Elsevier/ScienceDirect/Cell、Springer Nature、Wiley、OUP、Taylor & Francis、PLOS、Frontiers、MDPI、ACS、RSC、AAAS、JAMA、BMJ、NEJM、PMC 和预印本页面家族适配器；站点规则失败时自动回退到通用语义提取。
- 导航面板打开时对正文根节点进行防抖增量更新，关闭即断开观察器，避免长期持有页面 DOM。
- 逐段摘要改为按需生成，支持整篇或单章节；单章节缓存不会覆盖整篇缓存。
- 新增“章节 × 高亮类型”分布矩阵，可从章节、摘要或高亮计数跳回原文。

## 动态正文的文献类型同步

- 修复 ScienceDirect 等动态论文页先抽取少量正文、随后正文继续加载时，点击“分析全文”或“综述脉络”会错误提示 `Study type must be selected before analysis` 的问题。
- 弹窗现在把已准备文献的身份与旧正文指纹一并传给页面和后台；后台验证旧指纹属于该文献后，将新正文指纹合并进原记录，并保留用户已选的文献类型、备注和标注。
- 不可信、过期或不匹配的文献身份不会被强行复用，仍会退回当前正文重新建档。

## 新增叙述性综述类型

- 文献类型从八类扩展为九类，新增“叙述性综述（机制/转化）”。
- 适用于围绕生物学机制、临床前证据和转化机会组织内容，但没有系统检索、纳排流程或定量合并的综述。
- 新类型会区分综述作者的综合判断与单篇引用研究结果，并避免把动物或体外证据写成已经证实的临床获益。

## 验证

- 新增动态正文扩展后仍保留文献类型的回归测试。
- 新增弹窗—内容脚本—后台身份传递契约测试，以及九类文献类型覆盖测试。
