# Brevess 2.1.0

## 原生侧栏与按需激活

- 点击扩展图标后才注入论文提取模块，不再对所有网页自动扫描。
- 所有分析、导航、高亮分布、Figure 解读与状态都集中在 Edge/Chrome 原生右侧栏。
- 侧栏宽度可使用浏览器分隔条拖动调整；论文页面不再挂载持久悬浮面板。

## 单篇文献档案

- 为每个规范化网页地址生成一个确定的文章档案文件，不扫描或枚举整个保存目录。
- 保存手动荧光笔高亮、备注、自动粗下划线结果、文献类型、LLM 原始结果、证据台账、大纲/逐段摘要、Figure 解读和导航快照。
- 打开论文并点击扩展图标后，若检测到旧档案，会提示加载旧结果或重新分析。
- 支持单篇档案手动导出/导入；档案移除 API Key、鉴权头、完整 HTML 和图片数据。
- 页面正文版本不一致时采用部分恢复，不强行重放旧 AI 文本范围。

## 整机配置迁移

- 设置页新增完整迁移文件导出/导入。
- 可迁移提示词、正则规则、阅读视图、自定义类别、Provider/API Key、文献记录和反馈语料。
- 导入前二次确认；目录句柄不进入文件，迁移后需重新选择本地目录。

## 质量验证

- 525 项自动化测试通过。
- Edge 浏览器级测试验证：点击前无扫描、点击后注入、原生侧栏四视图、网页零持久覆盖层、单篇档案往返恢复、凭据脱敏和整机迁移入口。
