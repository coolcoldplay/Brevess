# Brevess 2.1.1

发布日期：2026-07-17

## 新增

- 侧栏顶部新增固定的“一键导出适配诊断包”，在 `documentHash` 尚未生成、正文提取失败或侧栏初始化未完成时仍可使用。
- 诊断包优先导出为 JSON.GZ，包含当前渲染 DOM、完整正文候选子树、选择器覆盖、适配器定义、开放 Shadow DOM、同源 iframe、最近成功的正文/结构快照，以及最多 40 条提取阶段与错误轨迹。
- 诊断包具有 v2 架构标识与内容校验，文件名包含站点和时间，方便针对具体出版社页面新增或修复适配器。
- 正文连接加入 15 秒上限、明确的失败/超时状态和“重新提取”按钮。

## 修复

- 诊断导出不再调用正文提取器；即使提取器抛错，仍能导出用于修复的页面证据。
- 文献类型不可选时的鼠标样式由持续等待改为普通禁用状态，避免造成浏览器仍在忙碌的误解。
- 侧栏不再永久停留在“正在连接当前论文”；失败后给出可执行的重试和诊断导出入口。
- 导出前后验证活动标签页，避免切换论文时把诊断包错配到另一页面。

## 验证

- Node 单元与 UI 合约测试覆盖诊断核心、失败隔离、内容脚本轨迹、gzip 入口和超时状态。
- Microsoft Edge 真实扩展自动化已验证 JSON.GZ 下载、解压、全文 DOM、选择器覆盖、强制提取器崩溃后的继续导出，以及失败重试 UI。
