# SCI Paper Logic Highlighter 2.1.6

- Adds one-click API-setting presets for Kimi, Zhipu GLM, Doubao (Volcengine Ark), Qwen (Alibaba Model Studio), Tencent Hunyuan TokenHub and classic API, Baidu Qianfan, and MiniMax.
- Each preset fills the official OpenAI-compatible Base URL, a current default model, bearer authentication, JSON mode, and verified visual-input capability where available.
- Keeps the existing editable OpenAI-compatible configuration: changing endpoint or authentication options switches the selector back to the custom preset, and the saved API Key is never overwritten or exposed.
