# Brevess 2.4.12

运行修订：`2.4.12-build39-storage-recovery-r12`

本版集中修复本地工作区恢复、全文问答持久化和目录授权三个相互叠加的问题。

## 全文问答恢复

- 扫描时不再只依赖可能过时的 `chat/index.json`，会校验并读取独立的 `chat/turns/*.json`。
- 当旧版本在新 manifest 生成后仍写入上一代问答文件时，只恢复时间晚于 manifest 的有效文件，避免把真正已清除的旧历史带回来。
- 恢复时以磁盘 manifest 的工作区代际升级浏览器本地记录，并把恢复后的代际同步给正文页。
- 历史 turn 文件会重新汇总进问答索引，因此重启浏览器后可直接显示完整对话。

## 保存可靠性

- 恢复自磁盘、但 IndexedDB 尚无对应记录的 turn 现在会按幂等 upsert 保存，不再抛出 `TURN_NOT_FOUND`。
- `TURN_NOT_FOUND` 等已知错误不再被包装成没有信息的 `Unable to complete the request`。
- 显式保存会等待目录写入队列真正排空；失败项目保留在待同步队列中，不丢数据。
- 对 OneDrive 常见的短暂文件锁和写入中断增加有限重试，并在通知中区分“需重新授权”“目录已失效”和真实写入错误。

## 文件夹授权

- 保存、扫描、清除按钮会在用户点击的同步阶段直接请求目录权限，避免后台 service worker 丢失用户手势。
- 侧栏重新获得焦点时会刷新 IndexedDB 中的目录句柄，设置页刚选好的目录无需重开侧栏。
- manifest 加入稳定公钥，今后的解压目录和版本升级使用固定扩展 ID `finhfnjbpidfakpmkghkfjlfcfpoandh`，目录句柄和本地数据库不会再因构建路径变化而整体失效。
- 从没有固定 ID 的旧版本升级到本版时需要最后重新选择并授权一次原文件夹；之后同一公钥的版本不再因安装目录变化反复丢失授权。

## 其他

- LLM 进度事件缺少分块计数时显示通用进度，不再出现 `NaN/undefined 个分块`。
- 新增工作区代际漂移、独立 turn 恢复、恢复后再次保存、暂时写锁重试、权限失败保留队列和固定扩展 ID 回归测试。
