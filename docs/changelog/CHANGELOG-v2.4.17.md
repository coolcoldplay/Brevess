# 2.4.17：智能检索、统一标注与可控分析范围

## 新增

- 全文问答新增“查找并高亮”：用户输入自然语言检索意图后，LLM 返回可回定位的原文证据，插件直接在正文中高亮。
- 新增全局类别“智能检索匹配”；检索结果沿用手动标注模型，可修改类别、填写备注并持久保存。
- 设置页支持类别规则的新增、编辑和删除，并按“类别规则、模型与分析、快捷键、本地数据、关于与反馈”分页组织。
- 文章导航标题新增分析范围复选框。默认包含摘要、引言、结果、讨论和结论，默认排除方法及其他附加部分。

## 改进

- 正则下划线可点击转换为可编辑标注，支持修改类别和备注。
- 手动标注悬停时显示类别与备注；摘句分布中的手动、AI、规则和智能检索结果均提供悬停预览。
- 导航段落行拆分为正文跳转区和右侧紧凑“概述”按钮。
- 正则匹配、LLM 全文分析、全文问答和智能检索仅使用导航中勾选的章节。
- 收紧 Springer Nature 等页面的正文边界，过滤 `Main`、机构访问提示、作者与指标区域；合并由无语义 DIV 碎片造成的过度分段。

## 兼容性

- 已保存的手动标注、正则请求、LLM 分析、全文问答和本地文章工作区继续兼容。
- 章节分析范围会随文章工作区保存；旧工作区未保存该字段时自动使用新的默认范围。
