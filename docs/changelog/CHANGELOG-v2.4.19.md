# 2.4.19：内置类别永久删除

## 新增

- 内置类别和自定义类别均可从类别标题旁点击“永久删除”。
- 删除内置类别后会保存本地删除记录，重启、重新加载和常规升级均不会自动恢复。
- 已删除的类别不再出现在类别目录、正则分析、LLM 分析、手动标注类别或离线规则提炼中。
- 类别页面下方新增“已永久删除的内置类别”列表；只有用户主动点击“恢复”后，类别才会重新出现。

## 数据与兼容

- 删除记录会进入完整迁移备份和本地目录 `categories.json`。
- 已有标注继续保留删除时的类别名称与颜色快照，不会因删除类别而丢失历史标注。
- 删除时同时清理该类别的本地规则覆盖和当前分析选择。
