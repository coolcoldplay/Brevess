# 2.4.20：分析工作流与双语设置

发布日期：2026-07-28

## 新增

- Provider 配置显示真实服务商名称，配置名称可直接编辑；支持从官方兼容接口在线刷新当前账号可用模型，并保留手动模型 ID。
- 全文问答支持自然语言检索命中的原文并按本轮自选颜色高亮。
- 全文问答输入框支持 `@` 选择导航章节作为本轮上下文，支持 `/` 调用可新增、修改、删除的快捷提示词。
- 设置页新增“分析模式”，可新增、改名、删除模式，并从全局类别目录勾选该模式使用的规则。
- Panel 追问预设支持名称和提示词的完整新增、修改、删除；连续追问完整保留，早期历史默认折叠。
- 单个类别的 AI 提示词与正则规则支持模块化 JSON 导入/导出。
- 设置页与侧栏加入全局中文 / English 切换。

## 调整

- 移除论文类型前置选择，LLM 分析在正文准备完成后即可运行。
- 供应商的静态默认模型更新到当前官方推荐，并优先以账号实时模型列表为准。
- 分析模式取代固定“阅读视图”，旧版已保存视图与研究类型仍可迁移读取。
