# 2.4.21：阅读工作流与本地缩写表

发布日期：2026-07-28

## 新增

- 导航模块新增“缩写表”，仅在本地从正文中提取明确声明的“全称（缩写）”“缩写（全称）”关系，过滤 Figure、Panel、Table 等结构标签，并按缩写字母顺序显示两列表格。
- 正则模式可选择不同分析模式；切换模式再次分析时保留其他模式已经生成的正则或 LLM 高亮。
- 全文问答的 `@` 章节选择覆盖含有后代正文段落的完整大纲章节。
- 科学标题、导航段落、Figure/Panel 内容和问答回复保留安全的 `<sup>` / `<sub>` 显示语义。

## 调整

- 全文问答移除冗余键盘提示，将精简模型选择与发送按钮放到输入框右侧；`@` / `/` 菜单支持点击外部或按 Esc 关闭。
- 在线模型发现新增真实下拉框，账号返回的全部模型均可选择，同时继续支持手动输入模型 ID。
- 导航叶级段落默认折叠；底部“析文”更名为“亮文”；语言控件改为直接点击 CH / EN 切换。
- “逐图解读”和“主图串解”保持同一行；Panel 字母改为高对比徽标，后续描述使用更轻的常规字重。
- 任务路由名称统一为“文段高亮（高亮匹配）”“段落概述”“逐图解读”“跨图串解”。
