# 2.4.24：导航补全、手动高亮模式联动与 Brevess 新图标

## 正文选区高亮

- 选中正文后弹出的类别规则默认与插件当前分析模式一致。
- 高亮小窗新增紧凑的“分析模式”选择器，可临时切换并选择其他模式的类别规则。
- 临时切换只影响当前小窗；下一次选中文本仍以插件全局当前模式为默认。
- 全局分析模式变更后，已打开的小窗会刷新到新的默认规则集。

## 导航与分析范围

- Cell 页面缺失官方目录项时，会回退到正文标题层级，补回 Highlights 与 Summary。
- 导航保留 References、Appendix、Extended data、Supplementary information、Acknowledgements、Author information、Author contributions、Funding、利益冲突与伦理声明等真实论文结构。
- 摘要、引言、结果、讨论和结论默认参与分析；方法、参考文献和附加材料默认不勾选。
- “展开”“折叠”“生成逐段摘要”控制条在导航滚动时固定于顶部。
- 逐段摘要任务按导航复选框的实际选择范围执行。

## 侧栏与品牌

- 缩写表改为与 P、Z 一致的方框大写 `A`，并移到全局工具栏、扫描恢复按钮左侧。
- 删除问答区“匹配类别”文字标签，发送/模型选择与高亮控件按统一三列网格对齐。
- 侧栏标题曾统一为“论文阅读助手 Brevess”，1.0.0 品牌发布时进一步简化为“Brevess”。
- 扩展图标替换为新版 Brevess 横线标志，并输出 16、32、48、128 像素图标。
