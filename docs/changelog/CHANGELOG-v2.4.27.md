# 2.4.27：35 类高级正则与 Zotero 全库回归

## 高级类别正则

- 为快速主线、机制证据链、批判性审评和综述证据综合中的 35 个高级类别加入实际可执行的内置正则。
- 规则覆盖已知背景、知识缺口、研究策略、关键结果、创新意义，以及关联、因果、机制中介、必要性、充分性、救援、剂量/时间、跨体系验证等机制证据层级。
- 补齐研究设计、人群边界、测量有效性、效应不确定性、统计稳健性、混杂与反向因果、因果过度推断、外部验证、外推边界、透明度等批判性类别。
- 补齐综述范围、证据共识、矛盾证据、异质性来源、证据质量、概念框架和作者综合判断等综述类别。

## 精度收紧

- 去除会把任意 `Alternatively` 判为替代机制的宽泛规则。
- 将因果效应限制为干预/暴露与结果动词之间的有界关系，避免裸 `led to` 和 `resulted in` 泛化。
- 将机制中介与必要性分开：裸 `required for` 只进入必要性，不再同时进入机制中介。
- 跨体系验证不再由裸 `in vitro and in vivo` 触发，必须带有验证、确认、复现或一致性结果。
- 异质性来源不再由裸 `significant heterogeneity` 触发，必须给出来源、驱动因素或解释。
- 删除将普通 `clinical relevance/importance` 当作“统计意义与实际意义”的宽泛命中。

## Zotero/Uminer 基准

- 只读扫描本地 Zotero Uminer 转换目录，不修改 Zotero 数据库或附件。
- 发现 989 个 `full.md`，其中 832 个通过论文结构筛选。
- 共检查 585,404 个句子，其中 209,118 个位于默认参与分析的核心章节。
- 47/47 个可用正则类别均在真实语料中触发；结构化摘要标签回归为 295/295。
- 基准报告增加类别命中密度、章节分布、规则触发覆盖、排除章节样本和类别冲突对。
