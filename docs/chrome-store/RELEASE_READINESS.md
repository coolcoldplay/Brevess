# 发布检查范围

当前公开版本为开发者模式安装的预览版，不代表 Chrome Web Store 已审核或所有回归已通过。

## 自动检查

- `npm run test:chrome-store`：ZIP 往返、路径边界、manifest 转换和发布文件清单。
- `npm run verify:chrome-store -- dist/<名称>`：运行依赖、压缩包完整性、逐文件 SHA-256 和静态凭据扫描。
- `npm test`：完整现有回归。部分测试依赖尚未随源码提供的历史 fixture、Windows 本机运行时，另有行为断言失败和超时；不得将静态打包成功当作全功能验收。

## 正式商店提交前

完成干净配置的首装、侧栏重启恢复、PDF、图目录、数据导入导出、凭据边界、中英文及至少一条真实 AI 路由测试；解决剩余失败，并使用最终版本更新截图和审核步骤。

网站的 AlphaFold 示例展示实际生成结果，具体范围与限制见 [实测素材说明](../media/alphafold-r27.md)。补充图目录抓取仍可能失败；AI 内容需要读者核对原文。
