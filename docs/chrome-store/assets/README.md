# 商店图片规范

正式商店素材应从最终发布包采集，展示真实操作并核对界面版本。网站素材与商店提交素材采用不同尺寸，不应直接混用。

- 128×128 PNG 扩展图标。
- 1–5 张 1280×800（或 640×400）真实截图。
- 可选 440×280 小推广图、1400×560 大推广图。
- 使用原创或获许可的论文素材，保留作者和许可归属。
- 不显示账户、密钥、个人笔记、标签页历史或本机路径；导出时移除图片元数据。
- 中英文截图分别检查文字和布局，不伪造 AI 输出。

辅助脚本：`scripts/generate-chrome-store-assets.mjs`、`scripts/capture-chrome-store-screenshots.mjs`。这些脚本使用 Playwright；自动采集结果仍需人工审核。
