# Brevess 1.0.0

本版本为 Microsoft Edge 外接程序商店首发候选版。

## 主要能力

- 从论文网页提取章节树、正文段落、Figure、Panel 和缩写表，并支持原文跳转。
- 提供四种可配置分析模式，以正则或用户自行配置的 LLM 定位和高亮证据。
- 支持手动高亮、类别与备注、固定短语白名单和黑名单。
- 支持逐图解读、主图串解、Panel 多轮追问和带原文证据跳转的全文问答。
- 按论文统计各功能、Provider 和模型的 Token 用量。
- 支持浏览器本地保存、用户授权的文件夹同步、JSON/PPT/Zotero 导出。
- 可选安装 Windows Codex Bridge；扩展本身不捆绑本地可执行文件。

## 首发候选版修复

- 修正自动高亮转为可编辑注释后无法完整清除的问题。
- 修正 Figure 快捷导航在快速移出时残留 Panel 菜单的问题。
- 修正已有本地目录时首次引导与重启恢复测试的页面状态处理。
- 统一隐私政策、设置页和安全说明的反馈邮箱为 `brevess0729@163.com`。
- 使用无版权合成论文重新生成并逐张核对商店截图。

## 验证

- 1104 项单元与契约测试通过。
- Microsoft Edge 完整端到端回归通过。
- 浏览器重启、本地目录恢复、批量删除与再次保存回归通过。
