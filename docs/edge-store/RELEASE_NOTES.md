# Brevess 1.0.1

本版本是 Brevess 1.0 系列的功能与隐私安全更新。

## PDF 研究工作区

- 支持在扩展内打开本地或网页 PDF，并通过 MinerU 生成可导航的章节、段落、Figure 和表格结构。
- 新增补充材料识别、补充 PDF 绑定、Figure 资产恢复和本机 PDF Figure 提取回退。
- PDF 解析结果、图片缓存和工作区状态继续遵循本地优先、大小受限的存储策略。

## 研究逻辑图与论文工作区

- 新增统一研究逻辑图，将逐图问题、结论、证据组和跨图机制链集中展示与编辑。
- 改进 Figure/Panel 提取、跨图综合、补充证据连续性和原文导航。
- 增强本地工作区恢复、跨标签页激活及版本升级后的内容脚本刷新。

## 配置备份与隐私

- 新增便携配置备份；API 配置仅以用户密码保护的 AES-GCM 密文写入授权文件夹。
- 导出、诊断与工作区快照统一清理 API Key、Token、认证头和其他敏感字段。
- GitHub 发布内容排除个人语料、浏览器资料、本地 PDF、测试截图和一次性 QA 输出。

## 发布与文档

- 将历史变更记录归档至 `docs/changelog/`，缩短 GitHub 仓库主页文件列表。
- 更新安装说明、隐私披露、发布脚本和第三方依赖声明。

## 验证

- 1418 项自动化与契约测试通过。
- PDF 本机宿主测试通过。
- Edge 发布包结构、版本、SHA-256 和敏感信息扫描通过。
