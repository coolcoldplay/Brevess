从下一篇论文开始。

  1. 下载并解压

    下载测试版，解压后保留该文件夹。

  2. 在 Chrome 或 Edge 中加载

    打开浏览器扩展管理，开启「开发者模式」，点击「加载已解压的扩展程序」，选择刚才的文件夹。

  3. 打开论文，配置模型

    在论文全文页点击 BREVESS，在设置中填写模型和 API Key，即可使用 AI。手动标注与工作台无需 API。
