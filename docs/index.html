从下一篇论文开始。

  1. 下载并解压

    将 ZIP 解压到长期保留的文件夹。更新时将新版文件覆盖到原目录，再重新加载 BREVESS。

  2. 在 Chrome 或 Edge 中加载

    打开浏览器扩展管理，开启「开发者模式」，点击「加载已解压的扩展程序」，选择刚才的文件夹。

  3. 打开论文，配置模型

    在论文全文页点击 BREVESS，在设置中连接本机 Agent 或填写 API Key，即可使用 AI。手动标注与工作台无需 API。
