完整安装教程 ↗
  1. 1

    下载并解压

    下载测试包，保留其中的 browser-extension 文件夹。

  2. 2

    加载插件

    浏览器扩展管理 → 开发人员模式 → 加载解压缩的扩展，选择该文件夹。

  3. 3

    打开论文，点击图标

    固定 BREVESS 图标，在论文全文页点击，开始导航、划句与记录。

无需 API 也能体验导航、手动标注与课题工作台。AI 功能使用你自己的模型与 API Key。当前为开发者模式安装的测试版。

开始前，了解这几件事

怎么和课题组一起测试？

先向负责人获取测试服务地址，在设置中心 → 账号管理 → 高级设置 · 服务连接中填写；注册并验证邮箱后，接受课题组邀请。公开备注也需要登录才能查看。

公开包不预置实际服务地址。当前服务连接与登录状态仅保留在浏览器会话中，完全退出浏览器后需重新连接、登录。

我的论文、笔记和 API Key 放在哪里？

阅读档案和配置以本机存储为主。AI 请求会向你配置的服务商发送所需内容；共享仅在你主动发布时上传对应备注。API Key 在本机填写，加密配置备份由你选择开启。

查看隐私政策 ↗
哪些能力需要额外配置？

翻译、AI 解图和问答需要模型服务；共享需要课题组服务；部分 PDF 增强能力和本机 Codex 接入需要可选本机伴侣，公开包不附带其二进制。页面提取效果也会受出版社与 PDF 结构影响。
