# 官网交互体验

官网的侧栏、文献雷达和课题工作台直接运行 BREVESS **1.0.2 r27 Adaptive Figures r10** 的 HTML、CSS 和界面代码。划句弹窗也直接导出插件组件，使用原 `content.css`；宿主页提供论文节选、引导提示和展开容器。手机端通过独立的触屏适配层，将同一套原组件重排为竖屏全屏体验；电脑端保留并排布局。

## 代码与数据

- `docs/assets/demo/native/`：插件原界面文件；`source-manifest.json` 记录版本、文件尺寸和 SHA-256。原 JavaScript、CSS 不作改写；HTML 入口仅注入隔离适配器、网络策略与 defer 标记，使原脚本并行下载、按文档顺序执行。
- `native-*.js`：用内存存储替代扩展通信和本机服务，仍调用原有渲染器、文献资源投影、画布模型、编辑与拖动逻辑。表格放大使用原表格阅读器。
- `scripts/website-selection-export.mjs`：导出完整划句、定位/拖动、正则匹配、双语翻译块与高清图查看器函数。构建清单逐函数记录 SHA-256，防止后续维护时误换成近似界面。
- `highlight-examples.js`：复用插件的类别定义，增加明确标注的“论文术语”示例情境。正则实际匹配原文；LLM 使用与原文偏移对应的 8 处预置语义标注。侧栏的类别、短语/整句模式、置信度分布、高亮分布和来源开关均使用原组件。
- `paper-data.js`：公开论文节选、人工整理的示例解读和翻译。不读取本机阅读记录、浏览器配置或 API Key。
- `native-reader-tools.js` / `native-sidebar-tools.js`：原版语义搜索、双语翻译、大纲和缩略词表的网页接入。`reading-tools-data.js` 提供公开节选的译文、术语释义与三组明确标注的检索示例；语义搜索阈值、定位和转备注实际执行。未覆盖的问题会说明示例范围。
- `native-image-tools.js`：原版图片悬停工具、局部放大镜、尺寸拖动、图片笔记和标注编辑器。高清查看器在论文区的独立框架内运行，保留旁边的侧栏和原版图注联动。预览在浏览器中缩至 600 px，HR 使用已下载的完整公开图片，重复查看复用同一资源。
- AI 按钮揭示预置内容，不发起模型请求，过渡时间不表示模型生成速度。账号、后台追踪和本机文件接入在安装后的插件中使用。
- 划句翻译支持准备好的原句与术语，其他选区会明确说明缺少预置译文。完整自定义规则编辑、任意问题推理和任意文本翻译需安装插件；演示入口会说明边界。
- 体验中的编辑、摘句、图片笔记/标注、缩略词与画布修改保存在内存；重置或刷新即清除。图片笔记同步到 Figure 备注，随侧栏保存进入体验文献库。Markdown 导出由用户主动触发。官网原有的语言偏好保留方式不变。

## 构建与验证

在仓库根目录运行（Node 22 或更新版本）：

```sh
node scripts/build-website-demo.mjs
node scripts/build-website-runtime.mjs
node scripts/verify-website-demo.mjs
python3 -m http.server 8764 --directory docs
```

默认从 `extension/` 导出。需要预览另一个已检出的插件版本时，显式指定源目录：

```sh
node scripts/build-website-demo.mjs --source /path/to/current-extension
```

打开 `http://localhost:8764/#features`。校验器检查原组件逐文件一致性、划句组件逐函数一致性、入口引用、适配器语法、遗留视频链接、意外导出的测试文件、本机路径、常见密钥格式和图片元数据。它不是完整插件回归，也不证明第三方模型回答质量。

`build-website-runtime.mjs` 从上述原文件生成 `assets/demo/fast/` 入口：按原顺序合并专用经典脚本，较大的公共依赖保留独立引用，供宿主页与各模块复用缓存；原作用域和界面不变，Mermaid 在首次绘图时加载。内容哈希用于缓存；清单记录每个输入与输出的 SHA-256。修改适配器或重新导出原组件后运行此构建，校验器会拒绝过期产物。官网在首个侧栏就绪后利用空闲时间依次准备工作台和网页体验；省流量或 2G 连接仅在进入模块时加载。

## 浏览器验收

本轮在 Chromium 中实测：

- 底部五个模块切换、双击显示预置内容；提示可关闭和重新打开。
- 实际鼠标划选、段落翻译、手动备注、高亮后再次打开备注。
- Figure 色块跳转；选择 Fig 2 与 Fig 4 后仅处理两图，取消多选后处理五图；Panel 展开与编辑。
- 问答发送、删除与重新生成；MSA 证据引用回到对应原文；原表格阅读器的放大、调节文字与关闭。
- 笔记生成、编辑保留、原 Markdown 导出。
- 侧栏编辑后的图解保存进体验文献库；将 Panel 拖入假说节点和组图规划，确认引用随真实画布模型保存。
- 雷达已读状态切换；文献库和画布模块切换。
- 窄屏采用下述竖屏交互；完整工作台不再以桌面宽度横向缩放。

### 划句与高亮修订验收

- 鼠标实际拖选文字，出现原版弹窗；阅读情境与颜色、翻译、手写备注、AI 解读均可操作。拖动位置和 Escape 关闭通过。
- 备注保存、点击原文重新打开、修改、从高亮分布跳回原文编辑、删除通过。
- “论文术语”正则匹配 10 处；可切换短语与整句。运行后折叠设置，显示原版高亮分布，并定位首个匹配段落。
- LLM 示例保留原有正则标注，按快速主线显示 8 处语义标注。阈值调到 95% 时保留 2 句、排除 6 句，图表与原文同步。
- 正则和 LLM 来源分别隐藏/恢复；清除自动高亮保留手动备注。修复了网页演示没有扩展握手，导致来源开关只改侧栏状态的问题。
- 390 × 844 下原版弹窗左右边界为 8 和 382 px，页面没有横向溢出。

### 阅读与图片工具

- 大纲标题双语显示；正文标题、段落和图题共 16 处预置翻译。停止翻译保留已显示内容，Alt 悬停可单独切换段落译文。
- 原版网页工具弹窗可控制划句、语义搜索和正文翻译。搜索支持三组示例、阈值筛选、前后定位、点击结果转为手动备注；未覆盖的查询不会伪造检索结果。
- 原版缩略词表支持填写中文名称、释义、手动修改、定位来源及加入术语记忆；补全示例保留手动编辑值。
- 图片悬停后显示 HR、放大镜、标注、尺寸和笔记五项原版工具。Fig 1 的 HR 从 600 px 预览切换到 1200 px 原图；尺寸按比例拖动、双击还原，离开图片后工具隐藏。
- 长按画笔打开原版查看器；箭头标注、保存、撤销/重做、切图后恢复、正文标注覆盖层可用。查看器支持缩放、适配窗口及侧栏图注；图片笔记关闭重开仍保留。

旧 MP4、WebM、GIF 演示和播放器已从当前官网移除；README 保留的历史截图有单独的采集说明。


### 手机竖屏体验

`mobile-demo.js/css` 组织全屏入口、原文抽屉和阅读保存；`native-mobile.js/css` 只在触屏体验开启时注入原页面。关闭或切回桌面宽度后撤销适配，不改写 `native/` 原文件。

- 五个原版模块保留图标与顺序，增加文字标签。单击切换，使用上方明确的 AI 按钮运行预置内容；解图卡片增加触屏多选，选中 Fig 2 与 Fig 4 后仅处理这两图。支持原版双击的入口仍保留。
- 原文在可收起的面板中打开；“试试选句”提供触屏快捷体验，使用原版划句弹窗、翻译、颜色分类和备注编辑器。原文工具提供翻译、语义检索与缩略词表。
- 图片提供直接可点的高清、放大/标注与笔记入口，运行原查看器和标注模型。
- 工作台底部保留四个模块。材料库和属性按需展开；点击“加入假说 / 加入组图”，选择实际节点或 Panel，调用原编辑会话保存引用、来源和备注。画布仍是原画布，可平移、缩放和编辑。
- 保存到课题会更新当前体验中的文献、图解、问答、笔记与高亮记录；相同材料可以被假说和组图共同引用。不会向已安装插件或本机资料夹写入。
- 手机端入口标明这是桌面插件演示，AI 为预置示例；不表示支持手机安装扩展。

本轮触屏验收覆盖 360 × 800、390 × 844、430 × 932；未出现页面横向溢出，五个底部模块保持可见。实际执行了备注保存、同一材料引用到假说与组图、Fig 2 / Fig 4 多选解读、Panel 展开、问答、笔记、正则与 LLM 高亮、语义检索、正文 / 大纲翻译、缩略词补全、图片缩放和矩形标注保存。雷达论文可返回精读原文，关闭按钮和浏览器返回可退出体验。

手机适配层在 1440 × 1000 下保持桌面论文区、侧栏和 iframe 的并排边界；本轮另按需求更新了论文区内部的 Nature 版式。原组件 213 个文件的哈希校验通过；新脚本未含本机路径或密钥，测试截图与测试记录不进入官网资源目录。

验收使用 Chromium 的触屏与视口模拟；原生 iOS Safari 和 Android 浏览器仍需真机复核。


### Nature 正文、网页滤镜与首屏动画

- 论文区参考真实 Nature AlphaFold 页面：期刊页头、文章日期、开放获取、作者、正文及图注排版，并加入随正文滚动出现的标题 / Download PDF 栏。只使用公开节选和原有图像，没有复制出版社的商业字体、广告脚本或账号信息。
- `filter-demo.js` 将原插件滤镜编辑器连接到左侧真实 DOM。可以点选干扰区、使用预置要求、预览、对比原貌、撤销、保存本页或停用。正文排版、图注和图文间距实际改变，原始文字与 Figure 保留。预览后自动滚动到保存操作。
- 官网只提供一篇样例；跨页泛化入口会说明需要安装插件并确认第二页，不伪造多页验证。AI 规则是预置演示，保存仅在此次网页体验中有效。退出编辑回到普通问答，清除选中目标和编辑面板；已保存效果保留。
- 实测隐藏浮动标题栏 → 对比原貌 → 保存 → 返回问答 → 正常回答 MSA 问题；再停用滤镜、将正文调到 20px / 行高 1.8 并撤销回原值，正文内容一致。
- 首屏隐藏白色导航，离开整个黑色滚动叙事区后再显示，回滚时隐藏。浏览器介绍一幕提供插件图标点击及原侧栏滑入动效，进度由滚动驱动，也可手动展开和收起。预览加载同一套原版侧栏，离开该幕后卸载 iframe，减少常驻开销；遵循减少动态效果设置。

### 不止论文

`web-demo.html` 在独立框架中复用相同的原版侧栏、划句、翻译和语义检索组件。按用户选择，GitHub 场景使用 `github-repository.json` 中的公开仓库快照，还原仓库导航、目录、提交行和完整 README，保留图片、表格与链接。图片随官网提供，运行时不请求 GitHub API 或原始文件服务。GitHub 标志来自官方 `https://github.githubassets.com/favicons/favicon.svg`，归 GitHub 所有。仓库动作可打开对应的公开页面，阅读标注在演示内完成；不会显示虚假的实时更新时间。

`chatgpt-conversation.json` 是用户明确指定并授权展示的完整“BREVESS优势比较”对话，包括原始提问、完整回答、表格、链接和引用标记。不包含账号信息、其他聊天、会话 ID 或本机元数据。对话为阅读快照，输入区把追问转入 BREVESS 示例问答。正文呈现为 ChatGPT 阅读界面，支持选句、标注和检索。网页身份贯穿标签页、滤镜与阅读工作区，避免切换来源后反复重试。

- GitHub / ChatGPT 场景切换；原文选句、预置翻译、手写备注与高亮；大纲定位和双击摘要；正则实际匹配与预置语义标注；语义检索和带来源跳转的网页问答。
- 手机端为原文 / 侧栏竖屏切换，保留原组件与底部模块；问答引用会切回原文。体验编辑仅保存在当前框架内存，刷新即清除。
- AI 结果与检索分数明确标为预置示例，不调用在线模型。未覆盖的查询说明示例范围，完整功能需安装插件。
- 已在 Chromium 桌面和 390 × 844 视口检查上述交互；手机划句与搜索弹窗在视口内，未出现横向溢出。

三个演示模块位于同一个视口容器，通过标签或下方箭头整体切换。内部原文和侧栏独立滚动，工作台与精读材料状态保留。移动端继续使用竖屏适配。

滚到演示区时对齐到导航栏下方的完整视口；外层滚轮按手势整体切换模块，惯性输入不连跳。原文、侧栏和文献列表优先内部滚动，到边界后重新滚动才换页；画布保留缩放手势。拖动滚动条或触屏浏览停在演示区中间时也会对齐，展开体验和弹窗不参与自动换页。
