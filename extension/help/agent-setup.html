连接本机应用

在设置的「模型与连接」中，选择想使用的应用。每次测试只发送一条简短测试消息。看到问答测试通过后，就能在侧栏选择它。

WorkBuddy 桌面版

  1. 打开 WorkBuddy，进入「专家·技能·连接器 → 连接器 → 自定义连接器 → MCP 服务管理」。
  2. 找到 brevess，点「信任」并启用，以便 WorkBuddy 读取浏览器。对 brevess-presentations 执行相同操作，它也负责聊天任务。
  3. 回到 BREVESS，选择 WorkBuddy 和「桌面客户端接单」，点「连接并测试」。点「复制给 WorkBuddy 的接单指令」，粘贴到 WorkBuddy 的新会话并发送。它会接收测试，回答会回到浏览器。

如果使用命令行，请选择「命令行直连」，并在该客户端的命令行中完成官方登录。

DeepSeek Harness 和 Codex

先在对应应用中登录，再回到 BREVESS 选择应用并测试。问答通过后会出现在模型列表。DeepSeek Harness 使用本机应用会话；DeepSeek API 的密钥在快速配置中单独设置。

Google Antigravity

选择 Antigravity 并测试。按提示安装官方 CLI 或进行 Google 账号登录。能够列出模型后仍需收到测试回答。如果 Google 提示账号地区受限，可以保留账号并使用其他服务。

首次安装本机组件

连接界面提示找不到组件时，展开「高级选项」，点「复制配置提示词」，粘贴到要连接的应用中并按提示完成。配置完成后回到 BREVESS 重新测试。
